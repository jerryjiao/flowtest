Demo site product notes (flowtest SUT): single-page task list at demo/index.html, served on port 4173. Sign-in gate: demo@flowtest.dev / demo-password (any other combination is rejected with a visible 'Invalid credentials' alert; the alert node itself stays in the DOM hidden at all times). Signed-in app: heading 'Tasks', textbox 'New task' + button 'Add' to create; per-task checkbox (accessible name = task text) to complete; Edit button renames inline (Enter saves, Escape cancels); Delete button removes. Summary line exposes extractable counters as data-field spans: open-count and done-count. 'Reset demo data' button in the footer restores the seeded task list ('Set up flowtest' done, 'Write first flow' open). Session lives in sessionStorage (fresh browser session = signed out); tasks live in localStorage.
